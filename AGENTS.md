# Portrait of us.

## Architecture

This is a fixed personal playlist, not a multi-playlist service or editor. It uses TanStack Start with React 19, strict TypeScript, Vite, and Netlify's TanStack adapter. The root page is the finished product. Do not add account management, content persistence, or public editing without a new request.

## Key files

- `src/routes/index.tsx`: responsive record-sleeve hero, ordered Spotify links, accessible player modal, photo gallery/lightbox, closing voice note, and clipboard sharing.
- `src/routes/__root.tsx`: document shell, product metadata, no-index and no-referrer metadata, global providers.
- `src/content/playlist.ts`: editable fixed playlist copy and media configuration. Photos are initially empty and the voice note is null because the owner has not supplied them yet.
- `src/content/tracks.ts`: 15-song snapshot from the supplied Spotify playlist, preserving order. Contains only title, artist, duration, and public track URL.
- `src/styles.css`: warm paper/sage palette, Cormorant Garamond headings, DM Sans body, Caveat annotations, record artwork composed with CSS, mobile layout and reduced motion handling.
- `public/img/cover.jpg`: actual owner-supplied artwork downloaded from iCloud. Do not replace it with generated imagery.
- `public/robots.txt` and `netlify.toml`: crawler opt-out directives and build settings.
- `src/components/ui/`: reusable Radix/shadcn components. Dialog provides focus trapping, escape dismissal, labels, and close buttons.

## Conventions and decisions

Keep personal content centralized in `src/content/`. This is configuration shipped with the fixed site, not mutable application data. Adding persisted editing later requires Netlify storage primitives and owner-only authorization.

Use local image paths via Netlify Image CDN. Add photographs under `public/img/` and update `playlist.photos` with src/caption pairs. Add a supported audio recording under `public/audio/` and configure `playlist.voiceNote` with src/title. The note stays at the end. Never fake a recording or use unrelated sample audio.

Keep Spotify ordering and accurate metadata. External song links open in a separate tab with noreferrer/noopener. Spotify embeds load only when the player dialog is opened. Full Spotify songs may require account sign-in.

The website is unlisted with advisory crawler suppression, not password protected. Anyone with the site address can view it. Do not claim strong access control. No secrets or credentials belong in client code, metadata, documentation, or logs.

Use named React components and functional state; browser APIs only inside event handlers/effects to preserve SSR. Use existing Dialog components for overlays. Preserve visible keyboard focus, meaningful accessible names, responsive layout, and reduced-motion behavior.

The deployment pipeline validates builds. Do not run build, start/dev-server, type-check, or test commands during automated editing runs when platform instructions prohibit them. Review changed files directly. The route tree is generated by the framework; do not edit it manually.
